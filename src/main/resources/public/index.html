Sequential HTTP Server

A socket-based Java server that answers one connection at a time. This page, its style sheet, its script and both images were delivered by that server as separate HTTP requests. The buttons below call its hardcoded services asynchronously: the page never reloads.

GET only no threads checking health…

Greeting

Sends a name to GET /app/hello?name= and shows the JSON greeting the server builds with it.

Square

Sends a number to GET /app/square?value=. The multiplication happens on the server, not in the browser.

Server time

Asks GET /app/time. The value comes from the clock of the machine running the server, which is why it differs from the browser clock once deployed on EC2.

Sequential limit

Calls GET /app/slow?ms=5000. Open this page in a second window, start the slow call here and immediately ask for the time there: the second request waits.
