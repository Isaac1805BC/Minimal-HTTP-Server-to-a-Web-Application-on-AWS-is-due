Sequential HTTP Server

A socket-based Java server that answers one connection at a time. This page, its style sheet, its script and both images were delivered by that server as separate HTTP requests.

GET only no threads one connection at a time

What the browser just did

Opening this address produced more than one request. The document arrived first; while parsing it the browser discovered the style sheet, the script and the images, and asked for each of them separately. Because the server is sequential, those requests were served one after another.
